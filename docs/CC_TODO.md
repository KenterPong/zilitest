## 階段二:拼字挑戰(技術規格第十二節 5.)

### 2. 出題邏輯(純函式 + 單元測試)

- [x] `splitTiles(language, term)`:英文逐字母(保留大小寫);日文依 `term` 逐字元(漢字、假名、ー、々、小字假名各一塊);韓文逐音節。重複字元各自一塊
- [x] `isSpellable(language, term)`:長度 2–12;只含該語言文字(日文含 ー、々),含空格、連字號、撇號、數字或符號則排除
- [x] `pickDistractors(language, term, sameLanguageTerms)`:3 個;不可出現在 `term` 中、彼此不重複(皆以正規化後字元比對:NFKC、大小寫、片假名=平假名);優先取同語言其他單字中與 `term` 同類型的字元,不足時英韓以備用表補(英 a–z、韓常用字表),**日文不補,有幾個算幾個**
- [x] `shuffleTiles`:正確字元若依原順序連續排列則重新打散
- [x] 單元測試涵蓋:重複字母、日文漢字+送假名、片假名含ー、韓文、排除含空格與符號的字、干擾字不與 `term` 重疊(含大小寫、片平假名正規化)、英韓備用表補足、日文不足 3 個不補
